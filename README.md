# Layoffs Data Cleaning Project
This project showcases a complete data cleaning process using MySQL on a dataset of tech industry layoffs.

  ## Objectives

  - Load & explore raw data
  - Remove duplicate data
  - Clean and standardize date formats
  - Remove or convert invalid values ('None', empty strings, NULL)
  - Standardize text & format
  - Prepare dataset for further analysis

  ## Tools Used

  - MySQL
  - MySQL Workbench
 
  ## Files in This Repository

  - `layoffs.csv`: Original Dataset
  - `layoffs.json`: Dataset converted from CSV to JSON
  - `datacleaning`: Cleaned dataset
  - `README.md`: Project documentation
 
  ## Sample Cleaning Steps

  - Converted `date` strings to proper DATE format
  - Replaced 'None' with NULL
  - Trimmed whitespace from text fields
  - Replaced missing values

  You can use this dataset for:
  - SQL analysis
  - Data visualization
 
  ## Skills Demonstrated

  - Data wrangling in SQL
  - Writing clear & logical SQL for cleaning
